# ShelfGuard

A lightweight food inventory web app for tracking packages, expiry dates, storage places and opened food.

## Run locally

Open `index.html` in a browser, or serve this folder from a local static web server. Data is currently stored in that browser's local storage; it does not sync between devices.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the files in this folder.
2. Open the repository's **Settings → Pages**.
3. Set the publishing source to the `main` branch and `/ (root)`.
4. Save and wait for the Pages URL to appear.

GitHub Pages publishes a public website. The inventory is stored in each visitor's browser and is not uploaded to GitHub.

## Current beta scope

- Food packages with individual expiry dates and open/consumed/discarded status
- Storage locations and food categories
- In-app expiry notices and weekly waste feedback
- Slovenian and English interface, light and dark themes

Push notifications, accounts, cloud backups and cross-device sync are not included yet.
